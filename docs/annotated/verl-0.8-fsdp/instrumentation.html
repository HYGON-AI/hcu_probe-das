★★ FSDP 0.8 头号坑 —— attn_implementation 必须 eager / sdpa，默认 flash_attention_2 训练每步 grad_norm NaN

HCU 上 FSDP 走 transformers → das flash_attn 包的非-varlen flash_attn_func。它在 hybrid 训推共卡运行时态下产 NaN——是运行时状态污染，不是 kernel 数学 bug（tripwire 钉死：把出 NaN 那次的确切入参 q/k/v standalone 重放，no-autocast / autocast(bf16) / sdpa 参照全干净）。

默认 flash_attention_2eager / sdpa
训练坏：grad_norm 每步 NaN、pg_loss/kl 间歇 NaN、reward 卡 0 不学（grad 被 clip/skip 故 run 不崩但不学）健康且在学：grad_norm 0.004~1.5 有限、reward 0.0125→0.21（学会 gsm8k）
dump311/317 module output NaN（第一个 NaN 精确在 layer0.o_proj 的 input = attention 核输出）干净（0 真 NaN）

修法：run 脚本 actor 命令行加 +actor_rollout_ref.model.override_config.attn_implementation=sdpa（或 eager；sdpa 更贴 vllm、更快、o_proj 尾巴更小，纯配置透传 AutoConfig 无需改码）。对比 Megatron：Megatron 用 TransformerEngine(TE) 融合 attention、根本不碰 das flash → 默认就好。这是 FSDP 比 Megatron 多的一条先决条件；没满足这条，验什么都没意义（在坏训练上验一致性是浪费、还会误判真问题）。

B 对齐 · 裁 response

为什么要裁 response

训推一致性只比 prefill 阶段。推理侧一个 request 的第一次 execute_model 是 prompt 的 prefill；训练侧默认前向吃的是 prompt+response 全长。要让两侧输入一致，就得在训练前向前把 response 裁掉，只留 prompt。

0.8 版本更全：除 input_ids/attention_mask/responses 外，还处理 position_ids 3 维分支（mrope）+ 裁 rollout_log_probs + 裁 response_mask——照 patch 抄，缺一个下游会 shape 不齐。

该模式纯采 dump 非真训练：response 裁空后 advantage/metric 无意义，属预期。

+ _hcu_m = self.model
+ while not isinstance(_hcu_m, torch.nn.Module) and hasattr(_hcu_m, "runnable"):
+ _hcu_m = _hcu_m.runnable
+ self._hcu_debugger.start(model=_hcu_m)
model_output = self.model(
input_ids=input_ids, positions=positions,
intermediate_tensors=intermediate_tensors,
inputs_embeds=inputs_embeds, **model_kwargs,)
+ if _hcu_on and self._hcu_dispatch_logger is not None:
+ self._hcu_dispatch_logger.log_step(scheduler_output)
+ if _hcu_prefill:
+ self._hcu_debugger.stop()
+ self._hcu_debugger.step()

只在 prefill 门控，防爆盘

推理侧被 dump 的那一次前向——锚点就是 model_output = self.model(...)，前后围 start / log_step / stop / step。

_hcu_prefill = 只在有新 request（prefill）时 dump：一个 response 要上千次 execute_model（decode），全 dump 会瞬间爆盘。只抓 prefill 那次即与训练侧对齐。

硬前置：① enforce_eager=True——vllm compile+cudagraph 会绕过 hook 导致 dump 空；② self.model 是 CUDAGraphWrapper，hcu_probe 只认 nn.Module，必须 循环解包 .runnable 才 hook 得中。prefill 走 eager（直接调 self.runnable）能命中；decode 走 cudagraph 不 dump，无碍。
