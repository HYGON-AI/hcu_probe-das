只在 prefill 门控，防爆盘

推理侧被 dump 的那一次前向。das v1 把 execute_model 的“只前向”和“采样”拆开，所以钩子挂内层 _model_forward（华为挂 return 前）。

两条 compare 路径

① 自研 verify_consistency.py（首选，绕 fused residual 盲区）
das 的 Qwen2DecoderLayer 为吞吐返回 (normed_hidden, residual) 两个 output（fused residual），HF 只返回一个完整 hidden。hcu_probe 自带 compare 会把 HF.output[0]（Max≈1688）错配到 vllm.output[0]（normed，Max≈2）→ 几千倍假 diff。解法：只比 normed 算子（每层 input_layernorm / post_attention_layernorm output）——norm 这个“检查点”两侧都算 rmsnorm(完整残差)、语义一致、可比。实测 1% 阈值 80/80。

② 官方 pt_compare --backend fsdp（交叉核对，2026-07-01 新增）
0.7 用 das vllm 0.18.1，会多 dump 72 个训练侧无对应的交错模块（Triton.kernel_unified_attention×24 + reshape_and_cache×24 + rotary_emb×24），vanilla 官方 compare 的 dual_monotonic_sort 会因两侧 module 位置无法同时单调递增而 raise。 run07_filtered.py 先过滤掉这些 bench-only 交错模块，再喂官方 pt_compare(consistent_check=True, backend="fsdp")。实测 可比叶子算子 98 个全 <1%（中位 0.153%、max 0.613% o_proj），确认自研 80/80 并扩到 o_proj/down_proj，与 0.8 官方同档。需容器 hcu_probe 含“修法B”（VerlShapeErrChecker）+ Megatron-LM 在 PYTHONPATH。
