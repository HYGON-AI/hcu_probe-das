hcu_probe × verl 0.7.1（Megatron 后端）—— 插桩位置标注

RL 训练里同一个模型既做推理（vllm rollout 生成 response）又做训练（Megatron actor 的 compute_log_prob 前向）。两侧对同一 prompt 的 prefill 前向理论上数值一致。hcu_probe 在两侧分别 dump 前向统计量，按 request_id 配对、比相对误差，定界精度差在训练侧还是推理侧。

本页标注 hcu_probe 在哪几个源码文件、哪几处方法插桩（绿色高亮 = 新增行，右侧是插桩说明）。全部改动靠 env 开关门控——不开 dump 就是 verl 原行为（最小侵入）。训练侧钩子全部落在 MegatronPPOActor（megatron_actor.py，LEGACY 路径），不是 FSDP 的 dp_actor、也不是 0.8.0 的 engine。

★★ megatron 0.7.1 最大的坑 —— 别加 use_legacy_worker_impl=disable，钩子必须挂 LEGACY 的 MegatronPPOActor

verl 0.7.1 的 actor 有两条执行路径：LEGACY（megatron_workers.py → MegatronPPOActor，即 verl/workers/actor/megatron_actor.py）和 NEW engine（verl/workers/engine/megatron/transformer_impl.py）。上游 async 文档 + 0.8.0 skill 都钩 NEW engine，靠 trainer.use_legacy_worker_impl=disable 强制走它。

但 0.7.1 的 NEW engine 的 compute_log_prob 有权重未物化 bug：前向一进第一个 leaf word_embeddings 就 F.embedding(masked_input, self.weight) 报 RuntimeError: The tensor has a non-zero number of elements, but its data is not allocated yet（EXIT=1），dump 全空。关键：DUMP_ON=0（零 dump 插桩）也照崩 → 隔离实验坐实这是引擎 bug、与 hcu_probe 无关。空 dump 是「forward 崩」的下游症状，不是「hook 到 0 module」。

修法 = 弃 NEW engine，钩 proven-healthy 的 LEGACY MegatronPPOActor；launch 不加 use_legacy_worker_impl=disable（默认 auto 即 legacy）。这也是与 0.8.0（钩 NEW engine 的 transformer_impl.py）、FSDP 0.7（钩 dp_actor）的核心区别。

+ while not isinstance(_hcu_m, torch.nn.Module) and hasattr(_hcu_m, "runnable"):
+ _hcu_m = _hcu_m.runnable
+ self._hcu_debugger.start(model=_hcu_m)
model_output = self.model(
input_ids=input_ids, positions=positions, ...)
+ if _hcu_on and self._hcu_dispatch_logger is not None:
+ self._hcu_dispatch_logger.log_step(scheduler_output)
+ if _hcu_prefill:
+ self._hcu_debugger.stop(); self._hcu_debugger.step()
核心（推理侧）
A 采集 · 推理侧（只 prefill）

只在 prefill 门控，防爆盘

推理侧被 dump 的那一次前向——挂内层 self.model(...)（with set_forward_context 块内）。

_hcu_prefill = 只在有新 request（prefill）时 dump：一个 response 要 ~上千次 execute_model（decode），全 dump 会瞬间爆盘。只抓 prefill 那次即与训练侧对齐。

★ CUDAGraphWrapper 解包：self.model 是包装器，hcu_probe 的 check_model 只认 nn.Module，要 while ... hasattr("runnable") 循环解包到真实 module 再传 debugger（prefill 走 eager 会命中，decode 走 cudagraph 不 dump，无碍）。硬前置：enforce_eager=True——compile+cudagraph 会绕过 hook 导致 dump 空。

② 推理 dump 不挂 rollout（0.7.1 legacy 实测）

legacy 路径下推理 dump 开着，step0 rollout 照常跑完、两侧 dump 都采到（与 0.8.0 / FSDP 推理 dump 拖挂 rollout 不同）。dump run 采完 step0 后停在 Training Progress 0%，是 PROMPTS_ONLY 裁 response 导致（训练-only run 不开推理 dump 也一样停），与推理 dump 无关。本流程只需前几步 dump 即可比对，别期望长跑；训练健康在 baseline 普通 run 单独验。

compare 路径（run_megatron_compare.py，5 步，无交错模块过滤）

官方 pt_compare(consistent_check=True, backend="megatron") —— A/B/C 备齐后离线跑，读两侧 dump.json 配对比数值。比 FSDP 0.7 更简单：das vllm 0.11 dump 模块序干净，不需要 FSDP 0.7 的 run07_filtered 那 72 个交错模块过滤（dual_monotonic_sort 直接能过）。

① 配对：strip(rid)=rid.split("-")[0] 去 das 的 -8hex 后缀；推理侧 dispatch_log（phase=prefill、requests=1）→ dump.json；训练侧 update_actor_log（num_requests=1）→ 按 step/rank 定位 dump.json。
② 挑同 prompt 样本：common = set(gen) & set(train)，只留 tok(train,["word_embeddings","VocabParallel"]) == tok(gen,["embed_tokens","VocabParallel"]) 的 rid（embed 输入 token 数相同 = 真同 prompt 完整 prefill）。
③ 比对（无过滤步）：pt_compare({"npu_path":train[rid], "bench_path":gen[rid]}, out, consistent_check=True, backend="megatron")。
④ 读 xlsx：双边 match，排除 TransformerLayer 整层 / IdentityOp，只留真叶子 output，统计 NormRelativeErr < 1%。

backend="megatron" 的关键：用 MEGATRON_MODULE_MAP（不是 FSDP_MODULE_MAP）把训练侧 mcore/TE 命名（decoder.layers.N.self_attention.linear_qkv.TELayerNormColumnParallelLinear …）对到推理侧 vllm 命名（model.layers.N.self_attn.qkv_proj.QKVParallelLinear …）；npu=训练 / bench=推理（方向反则 match 不上），SP 切片自动 cat。pt_compare = 华为 msprobe compare 的 HCU fork。

id 同源链（一处注入、两侧关联；★megatron 在 compute_log_prob 捕获）
agent_loop.generate 生成 vllm_request_id → 传 vllm + 写 extra_fields["request_id"] → 展开进训练侧 non_tensor_batch["request_id"] → compute_log_prob 开头捕获（★micro split 前，否则被丢）→ forward_step 按 _micro_dump_idx 取 → _log_update_actor_step 记训练侧 update_actor_log.jsonl；推理侧 dispatch_log.jsonl 靠同 id 关联（das 加 -<8hex> 后缀，compare strip 后对齐）。

验证结果（首验，Qwen2.5-0.5B + GSM8K，单节点 8 卡 HCU）

baseline 健康（无 dump，走默认 auto=LEGACY，与 dump 采集同一路径）：grad_norm 0.00047~6.3 有限无 NaN、reward 0.0125→0.66 在学、ppo_kl≈0、response 241~422 不截断。

dump：训练侧 dump.json 391 模块、推理侧 290 模块、NaN=0 / Inf=0；request_id 两侧交集 8/8（DP8 每 rank 1 样本）。
